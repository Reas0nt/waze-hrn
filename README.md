# Waze Hospitalario HRÑ — prototype

Navigable web prototype of a hybrid indoor wayfinding system for the Hospital Regional de Ñuble (Chillán, Chile): colored floor lines, QR activation points and an ultralight web page that works without installing an app.

Live demo: https://reas0nt.github.io/waze-hrn/

- `#acceso-principal` opens the route screen as if the QR at point A-01 had been scanned.
- Two critical routes: Farmacia de Especialidades (blue line) and Toma de Muestras (orange line, 2nd floor).
- Accessibility options: large text, high contrast, voice reading (Web Speech API), simulated guided mode.

The floor plan, distances and references are illustrative and must be validated on site.

Academic project — Proyectos Colaborativos de Innovación Regional Avanzados, IP Santo Tomás Chillán.
